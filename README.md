# Overview

As a software engineer looking to deepen my understanding of modern programming languages and object-oriented design, I built this **Recipe Organizer** application. 

This software is a command-line program written in Kotlin that allows users to seamlessly manage a collection of recipes. Users can add new recipes, view all stored items, search by name, edit existing details, and delete recipes. Each recipe includes structured data such as names, categories, ingredients, instructions, and preparation times. 

My purpose for writing this software was to gain hands-on experience with core Kotlin programming concepts—such as variables, conditional statements, loops, functions, and classes—while exploring advanced features like mutable collections and data classes to write clean and efficient code.
